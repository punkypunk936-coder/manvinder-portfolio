# Manvinder Arora Portfolio

Recruiter-facing portfolio for Manvinder Arora, covering crypto trading intelligence, publishing automation, live production tooling, market-flow dashboards and operator agents.

## Local Run

```sh
cd "/Users/manvinderarora/Documents/New project/portfolio-site"
python3 -m http.server 7777
```

Open `http://127.0.0.1:7777`.

All project cards link to public GitHub repositories. Private operator dashboards, credentials and runtime state remain outside the portfolio and public repositories.
