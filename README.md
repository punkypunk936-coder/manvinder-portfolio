# Manvinder Arora Portfolio

Recruiter-facing portfolio for Manvinder Arora, a crypto-native growth, community and business development operator. It presents operating outcomes, selected industry writing, three personal systems used in active workflows, and a concise one-page resume.

## Local Run

```sh
cd "/Users/manvinderarora/Documents/New project/portfolio-site"
python3 -m http.server 7777
```

Open `http://127.0.0.1:7777`.

All project cards link to public GitHub repositories. Private credentials and runtime state remain outside the portfolio and public repositories.

## Analytics

Privacy-light portfolio analytics are collected through GoatCounter. The public page has no analytics UI, cookies, or consent banner. Localhost traffic is excluded.

- Dashboard: `https://manvinder-portfolio.goatcounter.com`
- Tracks: page views, visitors, referrers, campaigns, browsers, and explicitly labelled portfolio clicks
- Clicks: resume, project repositories and previews, selected writing, meme/X links, LinkedIn, GitHub, and email
- Credentials: stored in macOS Keychain under `GoatCounter - manvinder-portfolio`

Analytics begin with the deployment that adds the tracking script; no historical GitHub Pages visitor data can be recovered.
